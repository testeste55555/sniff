# Riverside scene assets

Human Gate-approved WebP layers for the first riverside camp scene.

| Role | File | Canvas | Alpha |
| --- | --- | ---: | --- |
| Riverside background | `bg_riverside.webp` | 1536×1024 | No |
| Camp ground | `ground_camp.webp` | 1024×384 | Yes |
| Tent | `tent.webp` | 768×768 | Yes |
| Stump | `stump.webp` | 384×384 | Yes |
| Fallen log | `fallen_log.webp` | 768×320 | Yes |
| Rocks | `rocks.webp` | 768×256 | Yes |
| Grass | `grass.webp` | 384×384 | Yes |
| Foreground tree | `foreground_tree.webp` | 512×1024 | Yes |
| Character shadow | `character_shadow.webp` | 512×256 | Yes |

Day, dusk, and night use the same background. Time-of-day differences are applied by CSS tone layers rather than duplicate backgrounds.
