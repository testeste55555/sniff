# Fire assets

Human Gate-approved transparent WebP layers for the riverside campfire.

| Role | File | Canvas |
| --- | --- | ---: |
| Flame frame 1 | `fire_01.webp` | 256×256 |
| Flame frame 2 | `fire_02.webp` | 256×256 |
| Flame frame 3 | `fire_03.webp` | 256×256 |
| Low flame | `fire_low.webp` | 256×256 |
| Warm light | `fire_glow.webp` | 256×128 |
| Ground shadow | `fire_shadow.webp` | 256×128 |
| Embers | `fire_embers.webp` | 256×256 |
| Smoke | `fire_smoke.webp` | 256×256 |

All layers are metadata-stripped and contain alpha transparency. The static scene uses frame 2; animation can later switch the three flame frames without changing layout.
